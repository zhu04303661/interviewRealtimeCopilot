Getting started

Set up permissions

The microphone hears you; System Audio Recording hears the interviewer in your meeting app.

PermissionNeeded forWhere
MicrophonePractice and Live — your answersAsked the first time you start a session
System Audio RecordingLive — the interviewer's voiceSystem Settings → Privacy & Security → Screen & System Audio Recording
Screen RecordingSolve screen and auto-captureSame panel as above

Settings → Privacy & Stealth shows the state of each permission with a button to grant it. Preflight, the check before every session, lets you test the microphone level.

On Windows

Windows asks for the microphone the first time a session starts. For Live, meeting audio is captured through the screen-and-audio sharing prompt the app shows — allow it with system audio enabled so the copilot can hear the meeting.

On macOS, after changing a permission in System Settings, quit and reopen the app so macOS applies it.
