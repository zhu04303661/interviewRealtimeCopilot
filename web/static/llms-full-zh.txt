## 常见问题

### Interview Realtime Copilot 是什么？

Interview Realtime Copilot 是一款 Mac 上的 AI 面试助手。在实时面试中，它转写面试官的话、在中英文之间翻译、识别每个完整的问题，并基于你自己的简历和准备资料给出简短的回答。它还提供语音模拟面试，并在每场会话后生成复盘。

### 英语不够流利，它能帮上什么？

面试官说的每句话都会实时显示并附上中文翻译；每条回答提示都用可以直接说出口的地道英文写成，旁边附有中文。

### 它能帮忙解答编程面试题吗？

可以。按 ⌥S，它会读取屏幕上的编程题，用你选择的编程语言给出完整解法，并附上可以说出口的思路、时间和空间复杂度以及边界情况。在我们自己的评测中，从简单到困难的十道题，它给出的代码全部通过了测试。

### 面试官能看到它吗？

面试窗口默认不会出现在屏幕共享和录屏中，所以你在会议软件里共享屏幕时，它不会被包含在画面里。

### 我的数据存在哪里？

简历、资料、字幕、复盘和录音都保存在你自己的 Mac 上。只有在你开始的会话中，音频和回答所需的文字才会交给我们的 AI 引擎处理。

### 费用是多少？

免费版含每月 AI 额度，约可做两次语音练习。Pro 每月 £25 或每年 £169，额度为免费版的 20 倍。结账时加收当地税费。

### 支持哪些电脑？

搭载 Apple 芯片（M1 至 M4）、运行 macOS 14.2 及以上的 Mac，以及 64 位的 Windows 10（2004 及以上）或 Windows 11 电脑。

## 使用场景

- **Zoom、Teams、Meet 视频面试**: 分别听取会议声音和你的麦克风，在面试官说完时识别出完整问题，并基于你的简历给出一分钟内能说完的回答，你可以一直看着镜头。
- **用第二语言面试**: 面试官的每句话实时翻译（中英互译），回答提示同时给出两种语言，听得准、答得顺。
- **技术面与编程题**: 按 ⌥S，或交给自动截屏：读取屏幕上的编程题、架构图或报错，给出解法和取舍。
- **演练你准备的问答**: 上传准备文档，自动提取所有准备好的问题。AI 面试官用语音按顺序、随机或临场提问，每题追问一次，不重复。
- **回答到一半卡住**: 已经开口但思路断了？「补充回答」会接着你刚说的内容，补上你还没提到的关键事实。
- **每场面试后的复盘提升**: 每场结束都有复盘：逐题点评、指出遗漏，并给出更好的说法，还能回放录音。

# 面试指南

## 英语不够好，如何通过英文面试

https://copilot.xichiuk.com/zh/docs/english-interview.html

一套实用方法：听懂每个问题、清楚作答——以及 AI 面试助手能帮上什么。

### 英文面试为什么容易翻车

- 没听全问题：口音、语速或陌生术语，让你答非所问。
- 中文知道怎么答，却把时间花在脑内翻译上。
- 紧张会让这两个问题都更严重。

### 五个有效的做法

1. 提前把最可能被问到的十个问题用英文写成短句答案，并大声练习。
2. 把自己工作里的系统、指标、工具的英文说法记熟，这些词没法绕着说。
3. 用固定结构作答：先给结论，再讲原理，最后给一个数字或结果。
4. 没听清就说「Let me make sure I understood — you are asking about …?」，这很正常，也能争取时间。
5. 用语音模拟面试演练，而不是默读。说和读是两种能力。

### AI 面试助手能帮什么

Interview Realtime Copilot 会把面试官的每句话实时显示并附上中文翻译，说完后生成问题卡片，并基于你自己的简历给出地道的英文短答。面试前，语音练习会把你准备的问题大声问出来，让正式面试不再陌生。

把提示当作提词，用自己的话说。照着念会很生硬，扫一眼三条要点则不会。

## 身在国内，如何拿下海外远程工作的面试

https://copilot.xichiuk.com/zh/docs/overseas-remote-interview.html

时差、英文寒暄、陌生的会议链接——面海外远程岗位和国内面试有什么不同，该怎么准备。

工作内容一样，面试却完全不同：用第二语言作答、在奇怪的时间段上线、点开一个陌生的会议链接——而且远程团队对沟通能力的看重几乎不亚于专业能力，因为不在同一个办公室时，沟通本身就是工作。

### 面试之前

1. 书面确认时间时写清时区——「周三上午 9 点（太平洋时间）」——而不是「你那边早上」。海外团队按他们的时区约，自己换算记下。
2. 提前一天测试会议链接，安装桌面客户端而不是用浏览器。在国内请确认常用网络能打开链接；国内站（copilot.xichigroup.com.cn）可以直接下载应用，无需代理。
3. 用英文写一段 60 秒的自我介绍，大声说十遍。开场两分钟决定整场通话的基调。
4. 记熟自己工作中系统、工具、指标的英文说法。这些词在作答时没法绕开。
5. 准备两个反问的问题——团队跨时区怎么协作、入职第一个月做什么。远程团队考察的是你是否是个容易协作的人。

### 面试之中

- 寒暄是考核的一部分，不是废话。准备两个轻松话题——周末、工作环境——热情而简短地回应。
- 网络波动很正常。备好这句话：「抱歉，刚才好像断了一下，能再说一遍吗？」
- 慢一点没关系。回答前停两秒好过用语气词填补空白——在有延迟的通话里，停顿会被理解为思考。
- 需要时让对方把问题打在聊天框里——「能把这段贴在聊天里吗？」——尤其是有多个小问的问题。

### 副驾能帮上什么

Interview Realtime Copilot 会把面试官的每句话实时翻译成中文，并基于你自己的简历提示地道的英文短答——听漏一个短语不会导致答非所问，而你说出口的仍是自己真实的经历。通过国内站，国内可以直接登录和下载。

提示是提词，不是讲稿。海外面试官会追问，经历必须是你自己的，否则下一个问题就会露馅。

## 什么是 AI 面试助手（面试神器）？怎么选

https://copilot.xichiuk.com/zh/docs/ai-interview-assistant.html

这类工具在实时面试中做什么、选择前要看什么，以及它帮不上的地方。

AI 面试助手（也有人叫面试副驾、面试神器、面试外挂）是一类应用：旁听你的面试、识别问题，并在通话中实时给出回答建议。

### 选择时看什么

| 要点 | 为什么重要 |
|---|---|
| 回答是否基于你自己的简历和资料？ | 通用答案一听就知道；编造的经历经不起追问。 |
| 第一条提示多快出现？ | 超过几秒，沉默就会很明显。 |
| 能否听懂中间有停顿的问题？ | 真实面试官会边想边说；把一个问题切成三段的工具会给出三个错答案。 |
| 共享屏幕时是否不可见？ | 否则面试官会看到这个窗口。 |
| 能否用它演练？ | 第一次使用不应该是在正式面试中。 |
| 数据存在哪里？ | 简历和录音都是个人信息，保存在本机更安全。 |

### 它帮不上的地方

- 它不能给你并不具备的经历——好的工具也不会假装。
- 请了解每场面试的规则，并在规则内使用。

Interview Realtime Copilot 正是围绕这几点设计的：基于你的资料作答、不被停顿打断的问题识别、中英互译、语音练习，以及本地存储。

## 行为面试题怎么答：STAR 法则与高频问题

https://copilot.xichiuk.com/zh/docs/behavioral-questions.html

问题几乎是可以预测的——「讲一次你……的经历」。让回答出彩的是背后的结构。

行为面试考察的是你怎么做事，而不是你懂什么。面试官按评分表给每道题打分——主动性、冲突处理、影响力——所以一个啰嗦的真实故事，得分反而不如一个结构清晰的普通故事。

### 一分钟讲完 STAR 结构

1. 情境——一句话。在哪、什么时候、什么团队。忍住不要铺垫背景。
2. 任务——一句话。哪部分是你负责的，不是团队的。
3. 行动——占最多时间。三个动词：你决定了什么、做了什么、出问题后怎么调整。
4. 结果——一个数字或一个持续至今的改变。「发布从每周一次变成每天一次」好过「效果不错」。

### 覆盖大部分场次的八道题

| 问题 | 考察什么 |
|---|---|
| 自我介绍 | 不是讲故事——60 秒的弧线：现在、过去、为什么来这里。 |
| 与同事的一次冲突 | 你是升级还是化解；永远不要说「错在对方」。 |
| 一次失败的经历 | 真实的失败，以及你之后的改变。凡尔赛式回答在这题必死。 |
| 最有挑战的项目 | 你如何拆解过大的任务；一个讲深的故事好过五个泛泛的。 |
| 与上级的分歧 | 用数据表达分歧，一旦决定就全力执行。 |
| 快速学会新事物 | 考察方法而非天赋：你怎么找到关键的那 20%。 |
| 为什么选择我们公司 | 读他们的资料；说出具体的东西，而不是「你们文化好」。 |
| 超出职责的事 | 没人要求也主动承担——这是所有公司评分表都有的那一行。 |

### 真正有效的练习

写出来的 STAR 和说出来的是两种技能——口头版只有一半长度，还需要路标句（「……结果是」）。每个故事大声练到 90 秒内讲完。Interview Realtime Copilot 能把你的准备资料变成语音模拟面试，并在复盘里逐题点评，让结构被真正练到，而不只是写在纸上。

## 明天就面试、来不及准备：两小时计划

https://copilot.xichiuk.com/zh/docs/last-minute-prep.html

面试在即、时间不够时，按顺序该做什么。

1. 20 分钟：通读职位描述，划出反复出现的五项能力，这些就是考点。
2. 30 分钟：每项能力写一个真实例子：背景、你做了什么、带数字的结果。
3. 20 分钟：准备三道必考题：自我介绍、为什么选这家公司、为什么离职。
4. 40 分钟：对着模拟面试官把答案说出来，修改啰嗦的部分。
5. 10 分钟：检查麦克风、摄像头和会议链接，然后睡觉。

### 用副驾更快完成

上传简历、职位描述和手头的笔记。Interview Realtime Copilot 会提取问题，由 AI 面试官用语音提问；正式面试时，每条提示都来自这些资料——仅有的两小时可以用来演练，而不是写稿。

# 故障排查与常见问题

## 故障排查

https://copilot.xichiuk.com/zh/docs/troubleshooting.html

最常见问题的解决办法。

| 问题 | 解决办法 |
|---|---|
| 实时面试中「Computer」音量条不动（macOS） | 为应用开启「系统录音」权限，退出并重新打开，确认会议声音从这台 Mac 播放。 |
| 实时面试中「Computer」音量条不动（Windows） | 重新开始实时面试，在弹出的共享提示中允许共享并勾选「同时分享系统声音」。 |
| 「Mic」音量条不动 | 在「系统设置 → 隐私与安全性 → 麦克风」中允许，并检查 macOS 声音设置中的输入设备。 |
| 提示「本月 AI 额度已用完」 | 在「设置 → 账号」订阅，或等待下月额度重置。 |
| macOS 提示无法打开应用 | 「系统设置 → 隐私与安全性 → 仍要打开」（测试版尚未公证）。 |
| Windows 提示「已保护你的电脑」 | 点击「更多信息 → 仍要运行」（测试版尚未进行代码签名）。 |
| 无法连接账号服务 | 检查网络或代理；应用会保持登录并自动重试。 |
| 一个连续的问题被切成几段 | 通常是停顿过长；副驾仍会把它们合并作答。如果反复出现请告诉我们。 |
