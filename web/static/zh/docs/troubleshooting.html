问题解决办法
实时面试中「Computer」音量条不动（macOS）为应用开启「系统录音」权限，退出并重新打开，确认会议声音从这台 Mac 播放。
实时面试中「Computer」音量条不动（Windows）重新开始实时面试，在弹出的共享提示中允许共享并勾选「同时分享系统声音」。
「Mic」音量条不动在「系统设置 → 隐私与安全性 → 麦克风」中允许，并检查 macOS 声音设置中的输入设备。
提示「本月 AI 额度已用完」在「设置 → 账号」订阅，或等待下月额度重置。
macOS 提示无法打开应用「系统设置 → 隐私与安全性 → 仍要打开」（测试版尚未公证）。
Windows 提示「已保护你的电脑」点击「更多信息 → 仍要运行」（测试版尚未进行代码签名）。
无法连接账号服务检查网络或代理；应用会保持登录并自动重试。
